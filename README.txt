BAFAKAR HUB — FIRST WORKING FRONT-END

Included:
- Responsive Arabic RTL landing site
- Menu categories transcribed from the supplied photos (prices should be verified with the venue)
- Menu search and filters
- Local shopping/order list with WhatsApp message handoff
- Photo memory card editor (runs locally in the browser), PNG download, print inquiry handoff
- Branch information and contact/request form

HOW TO RUN
1. Extract the ZIP file.
2. Open index.html in a modern browser, or upload the folder to a static host.

IMPORTANT LIMITATIONS
- This is a working front-end prototype, not yet a deployed production system.
- Forms and order requests open WhatsApp; they do not create database records or confirm reservations.
- Photo processing happens in the browser; no image is uploaded to a server.
- Admin dashboard, live booking availability, secure backend, analytics, real payment, event management, and automated WhatsApp Business API are not included yet.
- Contact numbers and branch addresses should be confirmed with Bafakar before public launch.
- Menu text/prices are manually transcribed from the photos and may contain unclear/cropped entries. Please verify all items and prices before launch.
